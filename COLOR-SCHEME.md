# 🎨 Lonisa Mari Website - Color Scheme

- **Orange**: `rgb(255, 100, 55)` - #FF6437

## 🎨 Color Applications

### Header
- **Announcement Bar**: Gradient from yellow to orange

- **Brand Title**: Gradient text (orange → yellow → orange)

- **Action Buttons**: Orange borders, fills on hover

### Product Showcase
- **"Limited Edition" Heading**: Vibrant orange
- **"Snag it quick!"**: Orange with underline

- **Top Border**: Gradient accent line

### Newsletter Section
- **Background**: Subtle yellow-orange gradient overlay
- **Heading**: Gradient text (orange to yellow)
- **Input Focus**: Orange border with glow
- **Submit Button**: Orange-to-yellow gradient
- **Top Border**: Gradient accent line

### Footer
- **Link Hovers**: Yellow highlights on dark background

## 🎯 Design Features

### Gradients Used
1. **Header Bar**: Linear gradient (90deg, yellow → orange)
2. **Brand Title**: Linear gradient (135deg, orange → yellow → orange)
3. **CTA Buttons**: Linear gradient (135deg, orange → yellow)
4. **Newsletter Heading**: Linear gradient (135deg, orange → yellow)
5. **Newsletter Background**: Subtle vertical gradient

### Interactive Effects
- **Hover Animations**: Lift effect with shadow
- **Color Transitions**: Smooth 0.3s transitions
- **Focus States**: Orange glow on form inputs
- **Gradient Reversals**: On hover for buttons

### Typography Accents
- **Gradient Text**: Using background-clip for headings
- **Text Shadows**: Subtle shadows on yellow text for readability
- **Bold Weights**: Increased weight on colorful elements

## 🌟 Visual Impact

The color scheme creates a vibrant, energetic feel while maintaining:
- **Readability**: Dark text on light backgrounds
- **Hierarchy**: Color draws attention to CTAs and headings
- **Consistency**: Orange and yellow used throughout
- **Accessibility**: High contrast maintained
- **Brand Identity**: Warm, welcoming, playful aesthetic
